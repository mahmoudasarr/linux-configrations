# New-Fedora-Setup

A bash script to automate my Fedora post-install setup — removes unneeded
default apps, installs Nvidia drivers, sets up development tools (VS Code,
git, gcc/g++), and installs essential apps and Flatpak packages.

## What it installs

- Nvidia drivers (RPM Fusion)
- Development tools: VS Code, Git, GCC/G++
- Security & privacy: KeePassXC, Mullvad VPN, Mullvad Browser
- Apps: Brave, VirtualBox, Obsidian, Signal, Discord, gThumb.
